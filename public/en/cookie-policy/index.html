Cookie Usage Notice

Last updated: 22 July 2026. The website relies only on basic technical storage for settings.

1. Cookie definition2. Technologies used3. Language selection4. External services5. Data controls6. Notice updates

1. Cookie definition

Cookies are compact files that a browser stores. localStorage can serve a comparable purpose by retaining information on the user’s device.

2. Technologies used

The selection made in the cookie banner is saved in localStorage under the key pellironCookieChoice. This keeps the banner from appearing again. The website code contains no advertising, behavioural or analytics cookies.

3. Language selection

The active language follows the selected website section: /, /uk/, /ro/ or /en/. Changing language does not create a separate user identifier.

4. External services

Following an external link or launching an email application may direct the user to a third-party service with its own cookie policy. Third-party settings are outside this website’s control.

5. Data controls

The banner lets users allow or decline technical storage. localStorage entries can be removed in browser settings, and the banner will then be displayed again.

6. Notice updates

If analytics, embedded videos, maps or advertising tools are introduced, this policy and the consent mechanism need to be revised before those features go live.
